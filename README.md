A Windows desktop VPN client built on the
[TrustTunnel protocol](https://github.com/TrustTunnel/TrustTunnelClient).

[Download the latest version](https://github.com/ialexbond/TrustTunnelClientForWindows/releases/latest)

## Features

- Manage multiple VPN connection profiles.
- Choose direct or VPN routing for sites and applications.
- Use geographical and category-based routing lists.
- Reconnect automatically and switch to a backup server when configured.
- Manage TrustTunnel servers over SSH.
- View connection activity, traffic and server latency.
- Use light or dark themes and Russian or English interface text.

## Windows

The current release is Pro 3.2.0 for Windows x64. It includes the matched
TrustTunnel 1.1.11 core with Windows routing and process support.

The installer is unsigned. Previous builds triggered Microsoft Defender
detections.
