VPN-клиент для Windows с настройкой маршрутизации и управлением своим сервером.
Работает по протоколу [TrustTunnel](https://github.com/TrustTunnel/TrustTunnelClient).

[Скачать последнюю версию для Windows x64](https://github.com/ialexbond/TrustTunnelClientForWindows/releases/latest)

Light пока недоступна.

## Что умеет Pro

### Подключение к VPN

- Несколько подключений, у каждого свои настройки и карточка с задержкой до сервера.
- Добавление настроек из файла `.toml`, по ссылке `tt://` или `trusttunnel://`, перетаскиванием в окно.
- Передача подключения на другое устройство ссылкой или QR-кодом.
- Автоматическое подключение при запуске и переподключение при обрыве связи.
- Переход на запасной сервер в заданном порядке, если эта настройка включена.
- Аварийное отключение интернета при обрыве VPN, если включена соответствующая настройка.

### Маршрутизация

- Выбор, какие сайты и программы работают через VPN, а какие напрямую.
- Правила для доменов, IP-адресов и подсетей.
- Готовые списки стран и категорий сайтов с автоматическим обновлением.

### Управление сервером

- Пошаговая установка TrustTunnel на свой сервер.
- Добавление пользователей, смена паролей и выдача настроек подключения.
- Настройка сертификатов, сетевого экрана и защиты от подбора паролей.
- Просмотр состояния сервера, нагрузки и журналов, замер скорости.
- Обновление TrustTunnel на сервере, включение ускорения BBR и настройка прокси MTProto для Telegram.

### Интерфейс

Светлая и тёмная темы, русский и английский языки.

## Предупреждение Защитника Windows

В прошлых сборках Защитник Windows помечал файл `trusttunnel.exe` как вредоносный:
`Trojan:Win32/Bearfoos.A!ml` и `Bearfoos.B!ml`. Он может отправить файл в карантин,
после чего приложение не запустится. Такие срабатывания могут повторяться в новых сборках.

У программы пока нет цифровой подписи. При установке Windows также может показать
предупреждение о неизвестном издателе.
