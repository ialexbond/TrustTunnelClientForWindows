# TrustTunnel Client для Windows

Настольное приложение для VPN-протокола **TrustTunnel** — с обычным окном, кнопками и настройками,
вместо командной строки. У официального проекта TrustTunnel оболочки для Windows нет; эта её
добавляет.

Два издания в одном репозитории: **Pro** — подключение плюс полное управление своим сервером,
**Light** — только подключение.

[Скачать последнюю версию](https://github.com/ialexbond/TrustTunnelClientForWindows/releases/latest)

## Прочитайте до того, как скачивать

Это не формальности, а то, с чем вы действительно столкнётесь.

**Программа не подписана цифровой подписью.** Windows не может подтвердить, кто её выпустил, и при
установке покажет предупреждение о неизвестном издателе. Сертификат подписи стоит денег и требует
проверки личности владельца; он пока не куплен. Это не временный недосмотр — удостоверяющие центры
закрыли дешёвые пути его получения.

**Защитник Windows дважды помечал программу как вредоносную** (`Trojan:Win32/Bearfoos.A!ml` и
`Bearfoos.B!ml`). Это ложное срабатывание: вердикт приходит из облака Microsoft по хэшу файла, и
прилететь он может не сразу — в одном из случаев файл спокойно проработал под Защитником четверо
суток, и только потом попал в карантин. Карантин — не удаление: файл возвращается через
«Безопасность Windows» → «Журнал защиты» → «Разрешить на устройстве». Каждая новая сборка — новый
файл с нулевой репутацией, поэтому раз и навсегда это не лечится. Проверяли только Защитника; как
себя поведут другие антивирусы — никто не смотрел.

**Почему антивирусы нервничают.** Любой VPN делает ровно то, что описано в учебнике про вредоносное
ПО: просит права администратора, ставит сетевой драйвер, перенаправляет весь трафик и подменяет DNS.
Здесь всё это тоже есть, потому что иначе туннель не работает.

**Автор один, тестировщиков нет.** Часть поведения проверена только автоматическими тестами и ни
разу не наблюдалась на живой машине. Что именно — записано в проекте честно, а не замазано.

## Скачать и установить

Установщики — на [странице выпусков](https://github.com/ialexbond/TrustTunnelClientForWindows/releases).
Рядом с каждым лежит файл `.sha256` — контрольная сумма, по которой можно убедиться, что файл скачался
целиком и не подменён:

```powershell
Get-FileHash .\TrustTunnel.Client.Pro_3.0.0_x64-setup.exe -Algorithm SHA256
```

Только 64-разрядная Windows на процессоре x86 (x64). Сборок для ARM и 32-разрядных систем нет.
Минимальная версия Windows нигде не объявлена; разрабатывается и проверяется на Windows 10 и 11.
Если компонента Microsoft Edge WebView2 в системе нет, установщик докачает и поставит его сам.

Ставится **на весь компьютер**, в `Program Files`, поэтому и установка, и удаление просят права
администратора.

### Где лежат ваши данные

В папке вашей учётной записи: `%LOCALAPPDATA%\TrustTunnel Client Pro`. Там конфиги серверов,
известные хосты, правила маршрутизации, базы стран, журналы работы. В `Program Files` эта папка
намеренно **не** кладётся: туда у всех пользователей компьютера есть доступ на чтение, и ваши файлы
увидел бы любой, кто зайдёт под своей учётной записью.

Пароли от SSH хранятся не в файле, а в «Диспетчере учётных данных» Windows. А вот пароль к самому
VPN-серверу лежит в его `.toml`-конфиге открытым текстом — так устроен формат протокола.

**Удаление ничего не стирает по умолчанию.** Серверы, пароли и настройки остаются на диске.
Удалить их можно, только если поставить в деинсталляторе отдельную галочку «Удалить всё». Обновление
данные тоже сохраняет.

## Чем издания отличаются

| | **Pro** | **Light** |
|---|---|---|
| Версия | `3.0.0` | `2.7.0` |
| Подключение к VPN | да | да |
| Маршрутизация (что идёт через VPN, что напрямую) | да | да |
| Управление своим сервером по SSH | **да** | нет |
| Установка протокола на сервер мастером | **да** | нет |
| Внешний вид | переделан целиком в третьей версии | прежний, редизайн ещё не начинался |

Light — это Pro без раздела управления сервером. Если у вас уже есть конфиг от чужого сервера и
настраивать ничего не надо, хватит Light.

## Что умеет Pro

Пять разделов внизу окна: **Панель управления**, **Подключение**, **Маршрутизация**, **Настройки**,
**О программе**.

**Подключение.** Подключений может быть сколько угодно, каждое — своя карточка. Конфиг добавляется
файлом `.toml`, ссылкой `tt://` или `trusttunnel://`, перетаскиванием в окно, в том числе по
несколько за раз. У каждого подключения свои настройки: HTTP/2 или HTTP/3, MTU, аварийное отключение
интернета при обрыве туннеля, защита от блокировок, пост-квантовое шифрование, IPv6, адреса DNS.
Подключение переносится на другой компьютер QR-кодом.

**Переход на запасной сервер.** Если связь с текущим сервером действительно пропала, программа сама
уходит на следующий по вашему списку. Порядок задаёте вы, ненужные серверы из очереди выключаются.
Обратно приложение само не возвращается.

**Панель управления** (только Pro). Вход на ваш сервер по SSH — паролем или ключом. Дальше: установка
протокола пошаговым мастером (с отменой и откатом на любом шаге и продолжением после обрыва), выпуск
сертификата (Let's Encrypt, самоподписанный или свой), пользователи и их конфиги, межсетевой экран,
защита от перебора паролей с разблокировкой, BBR, MTProto, замер скорости, обновление сервера и его
журналы.

**Маршрутизация.** Правила «через VPN» и «напрямую», быстрые наборы в один щелчок, фильтр по
программам, самообновляющиеся базы стран и категорий.

## Чего нет

**Блокировки сайтов по имени домена нет** — её убрали, а не починили. Разбор показал, что
встроенное VPN-ядро не может отказать домену иначе, чем молча отбросив DNS-запрос, а Windows и
браузеры такой отказ обходят через другой адаптер. Вернуть её можно только фильтрующим DNS на вашем
собственном сервере — так это и делают все сопоставимые VPN.

**Режима SOCKS5 нет.** Старый конфиг с SOCKS5 при загрузке превращается в обычный туннель — то есть
через VPN пойдёт **весь** трафик, а не только трафик прокси. Учитывайте, если переносите старые
настройки.

**Цифра задержки на карточке — это не скорость туннеля.** Она показывает, отвечает ли сервер при
прямом обращении. Измерить задержку внутри туннеля приложение не может и не притворяется, что может.

**Чужой VPN-софт может помешать подключиться, даже будучи выключенным.** Подтверждено на Radmin VPN:
достаточно того, что его сетевой драйвер установлен в системе. В приложении есть обход, но это обход,
а не лечение.

## Как устроено

Это форк [TrustTunnel/TrustTunnelClient](https://github.com/TrustTunnel/TrustTunnelClient).
От исходного проекта взято **VPN-ядро на C++** — туннель, WinTUN-адаптер, перехват маршрутов и
аварийное отключение интернета. Графическое приложение написано с нуля здесь, в исходном проекте
его нет.

Ядро работает отдельным процессом рядом с приложением и живёт ровно столько же: приложение
закрывается — ядро тоже. Сейчас поставляется версия ядра `1.1.5`. Номера версий изданий с версией
ядра не связаны.

Приложение — Tauri 2, интерфейс на React 19 и TypeScript, серверная часть на Rust.

**Ветки репозитория.** На `master` — только само приложение и его проверки. Исходники C++-ядра и
сборочная система лежат на `release/tt-win-3.0.0` и в тегах выпусков; полное дерево берите оттуда.
Собранный бинарник ядра в репозитории не хранится — его нужно собрать.

`CHANGELOG.md` в корне — это журнал изменений **C++-ядра**, а не приложения (записи с `0.90.4` за
август 2022 по `1.1.5` за сентябрь 2026). Что изменилось в самом приложении, написано в описании
каждого выпуска и в окне «Что нового».

## In brief (English)

A desktop VPN client for Windows speaking the **TrustTunnel** protocol — a real window with buttons
instead of a command line. The upstream project has no Windows GUI; this supplies one. Two editions:
**Pro** (connection plus full server management over SSH) and **Light** (connection only).

Grab an installer from [Releases](https://github.com/ialexbond/TrustTunnelClientForWindows/releases).
x64 Windows only. Installs per-machine, so it needs administrator rights.

**The binaries are not code-signed**, so Windows will warn about an unknown publisher, and Windows
Defender has twice flagged them as a false positive — see the Russian section above for how to
restore a quarantined file. Read that section before installing.

This is a fork of [TrustTunnel/TrustTunnelClient](https://github.com/TrustTunnel/TrustTunnelClient).
The C++ VPN core is upstream's and ships as a separate sidecar process (version `1.1.5`); the GUI is
written here. Core sources live on the `release/tt-win-3.0.0` branch and in release tags, not on
`master`. The root `CHANGELOG.md` is the **core's** changelog, not the app's.

Everything here — core and application alike — is under the **Apache License 2.0** (`LICENSE`).
`NOTICE` records who holds what: the C++ core and the protocol are `Copyright 2020 AdGuard Software
Ltd`, the Windows application is `Copyright 2026 ialexbond`. Bundled third-party components
(Wintun, lwIP, the Microsoft runtimes, the Rust and npm dependencies) keep their own terms and are
listed there too.

The user interface and the release notes are in Russian and English; this README is primarily in
Russian because that is what the application's audience reads.
