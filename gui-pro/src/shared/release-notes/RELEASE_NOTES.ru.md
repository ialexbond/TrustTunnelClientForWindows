# Заметки о выпусках TrustTunnel Client Pro

Это собственный файл заметок приложения. Он вкомпилирован в сборку, поэтому окно «Что нового»
работает без интернета и всегда остаётся русским. Он же — единственный источник правды: описание
выпуска на GitHub не пишется вручную, а порождается из раздела нужной версии командой
`node scripts/release-notes-section.cjs 3.0.0`.

Файл разбит на части заголовками вида «## Версия X.Y.Z», новые сверху. Заголовок — только якорь
разбора: строку «Версия X.Y.Z» окно рисует само из номера версии, поэтому внутрь раздела номер
версии заголовком не повторяется. Дат в записях нет намеренно — их читают, чтобы понять, что
изменилось, а не когда.

## Версия 3.0.0

Приложение получило новый внешний вид: единая палитра, спокойные карточки и понятные состояния.
Ниже — только то, что видно при работе с программой.

### Панель управления

- Раздел собран заново: сервер, пользователи и защита теперь в одном месте.
- Обзор сервера идёт одной лентой карточек: адрес, нагрузка, срок сертификата, пользователи.
- Карточка сертификата показывает домен или адрес и тип сертификата, а не имя узла дважды.
- Список пользователей научился двум действиям прямо в строке, без раскрытия меню.
- Действия, которые идут долго, больше не прячут кнопку, а делают её неактивной.

### Установка протокола

- Установка идёт в одну кнопку и сама рассказывает, что делает прямо сейчас.
- Брандмауэр и защита от перебора настраиваются на том же шаге, а не отдельным походом.
- Порт управляющего подключения защищён отдельно: снятие защиты не может его закрыть.

### Подключение

- Один источник статуса на всё приложение: карточка, трей и заголовок окна говорят одно и то же.
- Разрыв связи с ядром больше не оставляет карточку в состоянии «подключено».
- Выход из одного окна больше не разрывает соединение, поднятое другим.
- Быстрое переключение между конфигурациями не оставляет за собой висящий процесс.

### Маршрутизация

- Списки исключений и прямых приложений редактируются без перезапуска подключения.
- Импорт и экспорт правил работают с обычными файлами и подтверждают результат.

### Настройки и «О программе»

- Настройки собраны заново: группы вместо сплошного списка, у каждой настройки короткое пояснение.
- Автозапуск, сворачивание в трей и язык интерфейса переехали в понятные группы.
- Вкладка «О программе» показывает и номер версии, и метку сборки — одной строкой, чтобы её было
  видно сразу, а не искать в меню.
- Проверка обновлений называет причину, если не удалась, и больше не выдаёт молчание за успех.
- Заметки о выпуске открываются в любой момент, а не только когда обновление найдено.

### Мелочи

- Уведомления перестали дублировать друг друга при быстрых переключениях.
- Пароли не попадают в журнал ни при каких обстоятельствах.
- Перетаскивание файла конфигурации в окно снова работает.
- Вставка из буфера обмена в поля управляющего подключения работает горячей клавишей.
- Тёмная и светлая темы больше не расходятся по контрасту подписей.
